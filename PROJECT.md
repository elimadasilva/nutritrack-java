# NutriTrack Project

## 🇧🇷 Português

### Visão do Projeto

O NutriTrack é uma aplicação de acompanhamento nutricional desenvolvida para ajudar os usuários a monitorar o consumo diário de calorias e proteínas.

O objetivo é oferecer uma experiência simples, rápida e intuitiva, sem funcionalidades desnecessárias.

### Público-alvo

Pessoas que desejam acompanhar o consumo de calorias e proteínas de forma simples, especialmente o público brasileiro.

### Princípios do Projeto

- Manter a aplicação simples.
- Permitir o registro rápido de alimentos.
- Oferecer uma interface limpa e intuitiva.
- Evitar funcionalidades desnecessárias.
- Facilitar a manutenção do código.
- Permitir expansões futuras.

### MVP — Versão 1

A primeira versão deverá permitir que os usuários:

- Registrem alimentos e suas quantidades.
- Calculem as calorias consumidas.
- Calculem as proteínas consumidas.
- Visualizem os totais diários.
- Consultem quanto falta para atingir as metas diárias.
- Verifiquem o estado da meta de calorias.

**Progresso atual:** a lógica básica dessas funcionalidades está implementada em Java. A interface do usuário e outras etapas necessárias para transformar o projeto em um aplicativo completo ainda serão desenvolvidas.

### Medidas dos Alimentos

Os alimentos poderão utilizar dois tipos de medida:

**Unidade**
- Ovo
- Banana
- Maçã
- Pão

**Peso em gramas**
- Arroz
- Feijão
- Carne bovina
- Frango
- Macarrão

Cada alimento possui um tipo de medida e uma quantidade de referência utilizada nos cálculos nutricionais.

### Interface do Usuário

A interface da aplicação será escrita em português.

Exemplos:
- Adicionar alimento
- Meta diária
- Calorias
- Proteínas

### Código-fonte

O código-fonte será escrito em inglês para manter a consistência dos nomes técnicos.

Exemplos:
- `Food`
- `FoodEntry`
- `DailyIntake`
- `GoalEvaluator`
- `calories`
- `protein`
- `quantity`

### Próximas Etapas

- Melhorar a validação dos dados de entrada.
- Criar testes automatizados.
- Continuar aprimorando a estrutura do código.
- Planejar a interface do usuário.
- Desenvolver as etapas necessárias para uma futura publicação.

### Objetivo de Longo Prazo

Aprender Java e desenvolvimento backend por meio da criação de uma aplicação real, útil no dia a dia e relevante para meu portfólio profissional.

## 🇺🇸 English

### Project Vision

NutriTrack is a nutrition tracking application designed to help users monitor their daily calorie and protein intake.

The goal is to provide a simple, fast, and intuitive experience without unnecessary features.

### Target Audience

People who want to track their calorie and protein intake in a simple way, especially Brazilian users.

### Main Principles

- Keep the application simple.
- Enable fast food registration.
- Provide a clean and intuitive interface.
- Avoid unnecessary features.
- Make the code easy to maintain.
- Support future expansion.

### MVP — Version 1

The first version should allow users to:

- Register foods and their quantities.
- Calculate calorie intake.
- Calculate protein intake.
- View daily totals.
- Check the remaining amounts needed to reach daily goals.
- Check the calorie goal status.

**Current progress:** the basic logic for these features is implemented in Java. The user interface and other steps required to turn the project into a complete application are still to be developed.

### Food Measurement

Foods can use two measurement types:

**Unit**
- Egg
- Banana
- Apple
- Bread

**Weight in grams**
- Rice
- Beans
- Beef
- Chicken
- Pasta

Each food has a measurement type and a reference amount used for nutritional calculations.
